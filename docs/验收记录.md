## 测试边界

- 单元测试采用人工数据。集成与界面测试只接受显式指定且已获授权的 cicddemo 仓库，源仓库仅用于读取和克隆。
- 隔离副本位于本项目 `.test-repos/`，Git 远端为本地裸仓库；镜像推送仅使用回环地址临时仓库，kubectl 使用模拟程序。
- 模拟部署不代表真实集群或业务可用性通过。真实环境需要部署者独立验证；不以截图作为完整链路证据。
